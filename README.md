# 🚀 LeetCode Progress Tracker

A modern **LeetCode Progress Tracker Dashboard** that helps users monitor their coding practice, problem-solving progress, difficulty-wise performance, and daily streaks.

## ✨ Features

* 📊 Overall performance dashboard
* 🟢 Easy / 🟡 Medium / 🔴 Hard problem tracking
* 🧩 Total problems solved
* 🔥 Daily coding streak
* 📈 Progress visualization
* 🏷️ Topics mastered
* 📊 Analytics dashboard
* 🌙 Modern dark-themed UI
* 👤 User profile section

## 🖥️ Dashboard

The dashboard displays:

* Total Problems Solved
* Easy Problems
* Medium Problems
* Hard Problems
* Current Streak
* Overall Performance Level

## 🎯 Project Goal

The goal of this project is to build a simple and visually appealing dashboard where users can **track and analyze their LeetCode problem-solving journey**.
